# Camping La Périgourdine — diffusion publique

Ce dépôt ne contient **aucun code source** : uniquement le build web de l'application de
gestion du camping, publié automatiquement par le CI du dépôt privé sur la branche
`gh-pages`.

## Installer sur iPhone / iPad

1. Ouvrir **https://laurentsar.github.io/camping-la-perigourdine-releases/** dans
   **Safari** (obligatoire — pas Chrome).
2. Bouton **Partager** → **Sur l'écran d'accueil**.

L'appli s'installe comme une icône autonome, s'ouvre en plein écran et fonctionne
hors-ligne. Les mises à jour sont automatiques au lancement suivant.

## Android

Utiliser l'APK publié dans les Releases du dépôt de code (installation hors Play Store).

## Données

Tout est stocké dans le téléphone (`localStorage`) : rien n'est envoyé sur un serveur,
rien n'est partagé entre appareils, et désinstaller l'app efface les données.
